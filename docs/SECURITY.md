# Безопасность

## Аутентификация

- Фловеон обслуживает выделенный **технический пользователь** SAP (Basic over HTTPS, LAN БОВА, D4).
- Пароль — в секрет-хранилище Фловеона, не в конфиге в открытом виде.
- На периметре — только HTTPS; самоподписанный сертификат допустим внутри LAN (`verify_ssl`).

## Полномочия (минимально необходимые)

- `S_SERVICE` — строго на 4 OData-сервиса (`ZMAT_SRV`/`ZPRICE_SRV`/`ZSTOCK_SRV`/`ZCUST_SRV`).
- Полномочия на ведение делового партнёра/контрагента — только нужные группы счёта/сбыт. орг.
- Не выдавать `SAP_ALL`/широкие профили техпользователю.

## CSRF

POST/модификация требуют `X-CSRF-Token` (Gateway по умолчанию). Коннектор делает Fetch→POST.

## Данные

- Читаются только минимальные стандартные поля контракта (open-core).
- Запись контрагента идёт через Z-ФМ с дедупом по ИНН/КПП — исключает дубли в KNA1.

## Аудит

- Логировать вызовы записи (создание/изменение контрагента) на стороне SAP (CMD_EI_API).
